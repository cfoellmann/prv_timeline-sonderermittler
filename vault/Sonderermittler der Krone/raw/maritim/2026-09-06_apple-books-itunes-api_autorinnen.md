# Apple Books / iTunes Search API (media=audiobook) — Autor:innen

**Quelle:** <https://itunes.apple.com/search?term=...&country=DE&media=audiobook&limit=200>
**Abgerufen:** 2026-09-06
**Methode:** Suche pro Serie in der Hoerbuch-Sparte des deutschen Apple-Katalogs. Das Feld `artistName` fuehrt dort die **Autor:in** (nicht wie in der Musiksparte den Serientitel). Zuordnung ueber Serienname + Folgennummer im `collectionName`, jede Zeile zusaetzlich ueber den Folgentitel gegengeprueft. Public-Domain-Namen (Jules Verne, Edgar Allan Poe, Arthur Conan Doyle, Oscar Wilde) und Serientitel-Fragmente wurden aus dem Feld entfernt.

**Belastbarkeit:** Einzelquelle. Die offizielle Fanseite `sonderermittler-der-krone.de` nennt **keine** Autor:innen, eine Gegenprobe war dort also nicht moeglich. Wo der Vault bereits eine Autorenangabe hatte (3 vergleichbare Faelle), stimmt Apple Books ueberein. Ausgeschlossen wurden die Parallellinien `Aus den Archiven` und `Reloaded`.
